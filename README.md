# Sarah Österhed — Portfolio

Personal portfolio site showcasing my work as a fullstack developer.

## Stack

- [React 19](https://react.dev/) + TypeScript
- [Vite 8](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)

## Fonts

- **Cabinet Grotesk** (headings) via [Fontshare](https://www.fontshare.com/)
- **Manrope** (body) via [Google Fonts](https://fonts.google.com/)

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
